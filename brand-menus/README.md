# BattleZone menu and branding update

This isolated updater adds the four changes requested by the project owner:

1. Background music follows its existing ON/OFF setting on menus, rules, history and results. It is silent on the shooting screen and while exporting replay video.
2. Hide decimal-score controls in the zeroing setup only.
3. Replace the old loading illustration with a simple BATTLE ZONE wordmark and three target illustrations.
4. Use the matching wordmark for the Android launcher icon.

The updater must back up changed files. It must not replace game.js, audio-data.js, timeout-audio.js, the existing BGM WAV, Gradle files or signing settings.
