# BATTLE ZONE — 시간제한 삭제 + 버튼 조작음

현재 정상 실행되는 **BattleZone_AndroidStudio 프로젝트에 적용하는 업데이트**입니다. 새 APK나 전체 프로젝트 ZIP은 아닙니다.

## 이번 수정

공기권총·공기소총·영점 사격에서 1발 제한시간과 전체 제한시간 기능을 제거합니다. 대기 설정창의 시간 조절 버튼과 사격 화면의 남은 시간 표시도 제거합니다. 단순히 숨기는 것이 아니라 시간초과 알림과 시간에 따른 자동 경기 종료 처리 자체를 없앱니다. ‘타임아웃!’ 음성이나 자동 0점 처리는 추가하지 않습니다.

10발·40발·60발 모드는 기존처럼 지정 발수에서 종료됩니다. 무제한 사격은 계속 사용할 수 있습니다. 실제 탄착만 발수와 점수에 반영됩니다. 개인 기록과 영상에 필요한 탄착 시각은 유지합니다. 기존 기록의 내용을 지우거나 바꾸지 않습니다. 경기룰 보기의 올림픽 공식 규정 설명은 그대로입니다.

앞서 요청한 버튼 조작음도 함께 넣습니다. 결과 보기·분석·설정·닫기·선택 등 소리가 없던 활성 버튼에 짧은 ‘톡’ 소리가 납니다. START 삑, 점수 음성, 발사효과음 미리듣기, 기존 잠금 효과음은 겹쳐서 재생하지 않습니다. 잠긴 버튼·탄착 입력·스크롤에는 버튼 확인음이 붙지 않습니다. 이 확인음은 결과 영상 오디오에 연결하지 않습니다.

## 적용 순서

1. 업데이트 ZIP을 PC에 다운로드한 다음 **모두 압축 해제**합니다.
2. 압축을 푼 폴더 안의 **APPLY_UPDATE.cmd**를 더블클릭합니다.
3. 기존 프로젝트가 `C:\BattleZone\BattleZone_AndroidStudio`에 있으면 자동으로 찾습니다. 다른 위치라면 경로를 입력합니다. `settings.gradle` 파일과 `app` 폴더가 함께 보이는 폴더를 지정합니다.
4. 초록색 **APPLIED** 또는 **ALREADY APPLIED**가 보이면 성공입니다. 창을 닫습니다.
5. 기존 프로젝트 폴더의 **BUILD_DEBUG_APK.cmd**를 실행해 APK를 다시 만듭니다. 예전에 성공했던 같은 PC와 프로젝트에서 빌드하세요.
6. `app\build\outputs\apk\debug\app-debug.apk`가 새 APK입니다. 휴대폰에 업데이트 설치합니다.

명령프롬프트를 사용하던 경우에는 적용 후 기존과 같은 명령으로 다시 빌드합니다.

```bat
cd /d "C:\BattleZone\BattleZone_AndroidStudio"
set "JAVA_HOME=C:\Program Files\Android\Android Studio\jbr"
gradlew.bat :app:assembleDebug
```

위 Java 경로는 Android Studio 기본 설치 위치 기준입니다. 기존에 다른 경로로 성공했다면 그 설정을 그대로 사용하세요.

## 보존 범위

프로젝트 전체를 덮어씌우지 않습니다. index.html의 시간 UI와 게임의 시간제한 처리 부분만 수정하고, 버튼 확인음 파일을 추가합니다. CSS·표적 그림·탄착 좌표 보정·점수 계산·음성·발사 및 시작 효과음·결과 스크롤·영상 생성 코드·Android Java·Gradle·앱 ID·서명 설정은 교체하지 않습니다.

적용 전에 index.html, game.js 및 기존 버튼 조작음 파일은 프로젝트의 `.range-update-backups/날짜-식별자/` 폴더에 자동으로 백업합니다. 구조가 예상과 다르면 원본을 수정하지 않고 멈춥니다. 여러 번 실행해도 중복 적용하지 않습니다.

APK 서명 충돌이 나면 앱을 무작정 삭제하지 마세요. 앱 삭제 시 기기에 보관된 기록이 지워질 수 있습니다. 같은 PC의 기존 서명 설정으로 빌드하는 것이 좋습니다.

## 시험 범위

동봉한 checks에는 별도 시험 화면에서의 버튼 오디오·마우스·터치 검사와 Windows PowerShell 적용/백업 검사, 시간제한 코드와 같은 구조의 시험용 코드에 대한 검사 결과가 들어 있습니다. 원래 프로젝트의 전체 APK를 다시 컴파일하거나 실제 휴대폰·전자타겟에서 시험한 결과가 아닙니다. 업데이트 적용 후 본인 PC에서 APK를 다시 빌드해야 합니다.
