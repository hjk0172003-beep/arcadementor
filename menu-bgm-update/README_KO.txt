BATTLE ZONE - 모드 선택화면 배경음 업데이트

1. ZIP 파일을 모두 압축 해제합니다.
2. APPLY_UPDATE.cmd 를 더블클릭합니다.
3. 음악 선택창이 나오면 Majestic_Modern_Electronic_Power_BGM.wav 를 선택합니다.
   이 WAV는 사용자가 보내준 원본 음악 파일입니다. 이 ZIP에는 음원 자체가 아닌
   업데이트 도구가 들어 있으며, 선택한 WAV를 원본 그대로 프로젝트에 복사합니다.
   WAV를 압축 푼 폴더나 다운로드 폴더에 두면 자동으로 찾습니다.
4. 프로젝트 선택창이 나오면 기존 BattleZone_AndroidStudio 폴더를 선택합니다.
   기본 C:\BattleZone\BattleZone_AndroidStudio 경로는 자동으로 찾습니다.
5. 초록색 APPLIED 가 나오면 기존 프로젝트의 BUILD_DEBUG_APK.cmd 를 실행합니다.
6. 새 app-debug.apk 로 설치합니다. 기존 프로젝트나 설치 앱을 먼저 삭제하지 마세요.

추가되는 기능
- 모드 선택화면에서만 배경음 반복 재생, 최초 설정 ON.
- 배경음 ON/OFF 버튼. OFF 선택은 다음 실행에도 유지됩니다.
- 사격 화면으로 전환할 때 바로 정지. START 대기/삑/사격/결과보기/영상 저장 때 음악 없음.
- 선택화면에서 개인 기록/경기룰 등 창을 열어도 음악은 잠시 정지합니다.
- 다른 앱으로 이동하거나 화면이 비활성화되면 정지합니다.
- 모드 선택화면으로 돌아오면 ON 설정일 때 재생합니다.
- 배경음은 별도 오디오로 재생되어 결과 영상 녹음에 연결하지 않습니다.
- 웹 브라우저에서 자동 재생을 막으면 첫 화면 터치 후 재생될 수 있습니다.

변경 범위
- app/src/main/assets/web/index.html 에 배경음 스크립트 연결 한 줄 추가.
- bz-menu-music.js, bz-menu-music.wav 추가.
- game.js / ui-button-sound.js / CSS / 시작 삑 / 발사음 / 점수 음성 / 타임아웃 /
  채점 / 표적 좌표 / 서명키 / Gradle 파일은 교체하지 않습니다.
- 이미 앞서 제공한 PowerShell 배경음 추가 코드를 적용했다면 중복 버튼 없이 갱신합니다.
- 원본은 프로젝트의 .menu-bgm-backups 폴더에 자동 백업합니다.

APPLIED: 적용 완료. APK를 다시 빌드해야 합니다.
ALREADY APPLIED: 이미 같은 업데이트와 음악이 적용되어 있습니다.
오류가 나오면 프로젝트를 삭제하지 말고 오류 화면을 보내주세요.

검증 범위
이 ZIP의 검사 결과는 tests 폴더에 포함됩니다. 설치기와 독립 배경음 모듈을
시험용 프로젝트/브라우저 화면으로 검사합니다. 실제 휴대전화, 전자타겟 및
사용자 PC에서 빌드한 APK의 재생은 별도 확인이 필요합니다.
