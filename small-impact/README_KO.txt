BATTLE ZONE - 탄착 원과 번호 크기 축소

[1] 이 ZIP을 PC에 다운로드한 뒤 마우스 오른쪽 클릭 -> 모두 추출하세요.
[2] BattleZone_SmallMarks_Update 폴더 안의 APPLY_UPDATE.cmd를 더블클릭하세요.
[3] 폴더 선택창에서 지금 APK를 만드는 BattleZone_AndroidStudio 폴더를 고르세요.
    app 폴더, settings.gradle, BUILD_DEBUG_APK.cmd가 함께 보이는 위치입니다.
    과거 폴더가 여러 개라면 현재 사용 중인 수정본 폴더를 선택하세요.
[4] 초록색 APPLIED가 나오면, 방금 선택한 게임 프로젝트 폴더의 BUILD_DEBUG_APK.cmd를 실행하세요.
[5] BUILD SUCCESSFUL이 나온 뒤 아래 새 APK를 휴대폰에 다시 설치하세요.
    app\build\outputs\apk\debug\app-debug.apk

업데이트 실행만으로 이미 설치된 휴대폰 앱이 바뀌지는 않습니다.
이번 ZIP은 작은 업데이트입니다. 전체 프로젝트나 APK가 아닙니다.
기존 프로젝트와 휴대폰 앱은 먼저 삭제하지 마세요.

[바뀌는 것]
- 지나치게 큰 번호 배지를 없애고, 탄착 원을 기존 2.25mm 반지름 계산 기준으로 축소합니다.
- 원과 숫자를 표적 확대 비율에 맞춰 함께 표시합니다. 별도의 큰 픽셀 배지를 얹지 않습니다.
- 번호는 원의 중앙에 작게 표시됩니다. 이전 탄착은 초록, 최근 탄착은 빨강입니다.
- 선택한 탄착을 위에 그리는 동작과 얇은 선택 테두리는 유지합니다.
- 메인 표적, 작은 표적, 결과 사진과 영상에서 같은 탄착 그리기 함수를 사용합니다.
- 4.5mm는 이 게임의 기존 표시 기준입니다. 실제 BB탄의 구경이나 물리 센서 설정을 변경하는 작업이 아닙니다.

[바꾸지 않는 것]
좌표 계산, 표적 실측 크기, 채점, CTC, 시간제한, 타임아웃 0점, 잠금,
시작 삑, 점수 목소리, 발사효과음, 배경음, 로딩 화면, 앱 아이콘,
표적지 색상 선택과 미리보기, 좌표 JSON 내보내기 삭제 상태,
기존 영점 표적 디자인, APK 빌드 설정, 앱 ID, 서명키 설정.

game.js 전체를 이전 버전으로 덮어쓰지 않습니다.
현재 game.js의 drawMarks 함수만 바꾸고, 함수 밖의 텍스트와 다른 파일들의 해시가 같은지 검사합니다.
기존 game.js는 프로젝트의 .shot-size-backups 폴더에 자동 백업됩니다.
기존 소스의 함수 인터페이스가 예상과 다르면 덮어쓰지 않고 중단합니다.
ALREADY APPLIED는 이미 같은 축소 업데이트가 적용되었다는 뜻입니다.

[확인 범위]
Windows 설치기 검사는 시험용 호환 프로젝트를 대상으로 합니다.
그리기 검사는 같은 새 함수로 수행하며, 전체 게임 APK나 실제 휴대폰 검증을 뜻하지 않습니다.
검사 기록은 verification 폴더를 참고하세요.
