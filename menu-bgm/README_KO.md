# 배틀존 — 모드 선택 화면 배경음 업데이트

이 ZIP은 현재 잘 작동하는 Android Studio 프로젝트에 적용하는 업데이트입니다. 전체 게임이나 APK가 아닙니다.

## 적용 순서

1. 이 ZIP을 다운로드하고 **모두 추출**로 압축을 풉니다.
2. 직접 올려준 **Majestic_Modern_Electronic_Power_BGM.wav** 파일을 압축을 푼 폴더에 넣습니다. **APPLY_UPDATE.cmd와 같은 폴더**에 넣으면 됩니다. 이 업데이트 ZIP에는 음원이 포함되어 있지 않습니다.
3. **APPLY_UPDATE.cmd**를 더블클릭합니다. 음원이 같은 폴더 또는 다운로드 폴더에 있으면 자동으로 찾습니다. 없으면 파일 선택창에서 그 WAV를 선택합니다.
4. 기존 프로젝트가 `C:\BattleZone\BattleZone_AndroidStudio`에 있으면 자동으로 찾습니다. 다른 위치라면 `app`, `gradlew.bat`, `settings.gradle`이 함께 있는 폴더 경로를 입력합니다.
5. 초록색 **APPLIED**가 나오면 완료입니다. **ALREADY APPLIED**는 이미 적용되어 있다는 뜻입니다.
6. 기존 프로젝트의 **BUILD_DEBUG_APK.cmd**를 실행해서 APK를 다시 만듭니다. APK 위치는 `app\build\outputs\apk\debug\app-debug.apk`입니다.

기존 프로젝트와 앱을 삭제하지 마세요. 이 업데이트는 기존 서명키나 빌드 설정을 교체하지 않습니다.

## 배경음 동작

- 모드 선택 화면 상단에 **배경음 ON / OFF** 전환 버튼 하나를 추가합니다.
- 기본값은 ON이며 ON/OFF 선택을 해당 기기에 저장합니다.
- 모드 선택 화면에서만 반복 재생합니다.
- 사격 화면으로 이동하면 즉시 멈춥니다. START 대기·삑·사격·결과·영상 저장에는 배경음이 섞이지 않습니다.
- 모드 선택 화면으로 돌아오면 ON일 때 다시 재생합니다.
- 모드 선택 화면 위에 경기룰·기록·설정 선택창이 열리거나 앱이 가려지면 일시적으로 멈춥니다.
- 효과음과 구별되도록 배경음 재생 볼륨을 22%로 설정했습니다. 원본 WAV 자체는 자르거나 변환하거나 가공하지 않습니다.
- 일반 브라우저가 자동 재생을 막으면 모드 선택 화면을 처음 누른 뒤 재생합니다. 기존 Android 앱의 자동재생 설정은 바꾸지 않습니다.

## 보존 범위

`game.js`, 표적 이미지, 점수 음성, 발사효과음, 직접 제공한 시작 삑, 시간제한·타임아웃 0점 처리, 잠금, 좌표 보정, 스크롤, 영상 생성, Java, Gradle, 서명 설정은 교체하지 않습니다.

바뀌는 파일은 아래 세 개입니다.

- `app/src/main/assets/web/index.html`: 배경음 스크립트 연결 한 줄 추가
- `app/src/main/assets/web/menu-bgm.js`: 독립 배경음 제어 파일 추가
- `app/src/main/assets/web/mode-selection-bgm.wav`: 선택한 WAV를 그대로 복사

변경 전 파일은 프로젝트의 `.bgm-backups/날짜-번호/`에 백업합니다. 다른 기존 웹 파일의 SHA-256을 비교하고, 변경된 것이 발견되면 업데이트를 되돌립니다. 이미 적용된 상태에서 다시 실행해도 버튼이나 음악이 중복 추가되지 않습니다.

배경음은 기존 녹화용 오디오 연결에 연결하지 않습니다. 저장 영상에 배경음이 들어가지 않습니다.

## 확인 범위

동봉한 `verification` 폴더는 별도 시험용 프로젝트에서 실행한 검사 결과입니다. 실제 사용자 프로젝트 전체 APK의 재빌드나 실제 휴대폰 시험 결과가 아닙니다. 본인 WAV의 정상 재생과 최종 APK는 적용 후 확인하세요.
